# 리플레이 이미지 (9-5단계)

리플레이 화면(`ui/ReplayView`)이 이 폴더에서 아래 두 파일을 찾는다. 없으면 도형으로 대신 그린다.

| 파일 | 크기 | 내용 |
|---|---|---|
| `replay_pit.png` | 1600×1000 (16:10) | 위에서 내려다본 바론 둥지. 유닛·글자 없음, 가운데 바닥은 비워 둔다 |
| `baron_token.png` | 512×512 | 원 안의 바론 얼굴. 원 바깥은 단색 `#06121A` |

그림이 바뀌어 바론·포탑·하이머 자리가 어긋나면 `data/replay.json`의 좌표(0~1 비율)만 고친다.
스킬·아이템·하이머 아이콘은 여기 두지 않는다. 실행할 때 Data Dragon에서 받아 `~/.heimer-baron-sim/icons/`에 저장한다.
